# allowed-origins.txt — the origins this estate is allowed to point DNS at.
# Consumed by scripts/dns-origin-audit.sh. Anything not listed here is a finding.
#
# WHY: on 2026-09-08 several jewell.nexus records were still aimed at a
# shared-hosting IP the cPanel account had been migrated off. That box answers
# every unmatched hostname with a redirect to whichever customer is now its
# default vhost, so visitors to those subdomains were sent to an unrelated
# third-party site. Nothing was compromised. The records were simply
# pointing at a stranger.
# An explicit allow-list makes that state impossible to hold silently.
#
# FORMAT (one per line)
#   ip     <address>    an origin server address we control today
#   suffix <domain>     a CNAME/MX/NS target suffix we trust
#   deny   <address>    known-dead; always reported, never tolerated
#
# ------------------------------------------------------------------------
# DENY — the dead shared-hosting box behind the 2026-09 incident.
# rDNS s4936.fra1.stableserver.net, WHG Hosting Services Ltd (World Host Group),
# Frankfurt. Our account no longer exists on it: the certificate it presents for
# our hostnames is a stranger's. Nothing of ours may ever point here again.
deny 65.181.113.13
